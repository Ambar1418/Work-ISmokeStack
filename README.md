# SONIA — The Architect of Clarity

An interactive, one-page botanical storytelling experience exploring Sonia's professional identity, thinking philosophy, and leadership journey.

> *"See the unseen. Connect the dots. Make things simpler."*

## Concept

The experience uses a living tree as its core interface across seven continuous scenes:

1. **The Seed** — Seed-to-tree growth sequence & editorial identity
2. **The Roots** — Five interactive thinking principles (`Observe`, `Understand`, `Simplify`, `Connect`, `Align`)
3. **The Trunk** — Five interconnected disciplines (`Brand`, `Demand`, `Communication`, `Operations`, `People`)
4. **The Branches** — Chronological career growth paired with concurrent parallel advisory & fractional roles
5. **The Leaves** — Twelve interactive expertise clusters linked to career milestones
6. **The Philosophy** — Staggered editorial beliefs
7. **The Connection** — Complete living tree ecosystem

## Tech Stack

- Next.js (App Router)
- React & TypeScript
- Tailwind CSS
- Framer Motion
- Custom interactive SVG botanical structures
